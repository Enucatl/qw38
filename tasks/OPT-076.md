## Evidence and mechanism

`q4k_decode_dots.cuh::vec_dot_q4k_group_loaded` constructs byte arrays,
shuffle-reduces dot and sum inside each K block, and returns zero in three
of four lanes. Pinned llama's `vec_dot_q4_K_q8_1_impl_vmmq` accumulates scaled
local packed dot/sum contributions before the outer row reduction. Merely
having DP4A does not remove Quartz's repeated communication and scalar work.

## Implementation

1. Add a focused optimized Q8Block sibling in the existing Q4 translation unit.
   Use legal packed 32-bit loads, masks/shifts for low/high nibbles, independently
   decoded scale/min groups, and exact integer dot/min-correction sums.
   Keep each lane's FP32 contribution throughout K; reduce once at row end.
   Preserve scale boundaries: do not accumulate integer products across blocks
   having different scales and apply one scale at the end.
2. Start from the control admitted by OPT-075. Screen exactly two candidates,
   two and four warps/row, on gate/up 17408x5120 and down 5120x17408. Preserve
   the selected separate/paired FFN composition and SwiGLU rounding. Shared
   activation loads across gate/up are retained if paired; this is not another
   fusion-layout study. Do not change Q8/Q6 or prompt MMQ.
3. Half-scale staging is outside this change: retain FP32-scale Q8Block so
   changed reduction is separable. Never substitute rounded half(sum(q)) for
   integer min-correction sums. Compare error to independent exact staged
   dots and original-input GPU-calibrated budgets.
4. Show DP4A/word loads and absence of K-loop shuffles in SASS or disassembly.
   Record registers, local bytes, occupancy and compiled variants. If available,
   one ncu launch for control/survivor measures issue/stall and traffic, not a
   broad metric sweep. Reject if added spills remove the complete saving.
5. Time full rotating FFN against current production with identical staging,
   graph policy and outputs. Update eager/prequant/paired dispatch only after
   the common admission gates. A missing numerical prerequisite is a no-go;
   an OPT-075 performance rejection with valid admission permits this new
   mechanism, still measured against packed if packed remains production.
