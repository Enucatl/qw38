## Implementation recipe

1. Read `tools/production_numerics.py`, `src/opt044_production_numerics.cpp`,
   `cuda/production_numerics.h`, `cuda/quant_mmv.cu` admission functions,
   `tests/test_production_numerics.py`, the OPT-044 report and OPT-043 captures.
   Preserve all v1 evidence and callable strict kernels. Add
   `pins/production_numerics_v2_contract.json` and a current admission manifest.
2. Extend `tools/llama_authority/component_gap.cpp` or a sibling native target
   to export actual GPU projection outputs for supplied GGUF tensor rows and
   exact FP32 expansions of Quartz BF16 captures. Bind the backend stream;
   synchronize before reading outputs. Export the actual quantized activation
   bytes/scale/sum when inspecting staging. Do not substitute a CPU reimplementation
   for GPU output or silently change the llama revision.
   Audit the existing staging mismatch explicitly: Quartz stores half(sum(q))
   in `Q8_1Block::q8_sum`; pinned llama stores half(sum(original x)). Pinned
   Q4 MMV ignores that stored sum and recomputes integer sums. Integers above
   2048 can lose units when Quartz stores them as half. Label the existing
   format honestly; add a distinct true llama staging variant if needed. Do
   not reinterpret existing staged buffers. Compare scale, quants and sum
   separately, with integer sums 2047,2049,4064 and their negative counterparts.
   Any consumer change is a separately measured candidate, not a fixture repair.
3. Freeze calibration/held-out case IDs before running candidate tuning:
   calibration layers 0,3,31,32; held-out 62,63 and distinct token positions.
   Use Q4 gate/up K5120 and down K17408; Q8 mixer K5120 and K6144; Q6 vocab
   K5120. Select at most 16 output rows and 4 captured activations per family/K.
   Extract actual down/SwiGLU inputs and final-norm vocab inputs; OPT-043's
   preprojection captures alone are insufficient. Add those bounded captures
   to the current diagnostic if needed. Record offsets, tokens, stage and hashes.
4. Add complete small probes: Q4 17× 256, Q6 17× 256, Q8 17× 32; each has zero,
   alternating cancellation, finite large/small scales and deterministic random
   input. Arbitrary bytes interpreted as FP16 scales must not create accidental
   NaNs. Malformed/nonfinite input tests are separate failure tests.
5. Independently decode each selected weight row once into FP64. For each
   exact input, compute two references: original BF16 values, and the candidate's
   own staged values including half-rounded scales/sums. Measure max abs, RMS,
   normalized RMS, cosine where nonzero, and nonfinite count. The second reference
   detects unpack/scale/min bugs; the first measures total quantization error.
6. Freeze production total-error ceilings per family/K and input class from
   **reference-only** calibration: `max(strict_ceiling, 1.25*llama_gpu_error +
   1e-6)` for max abs/RMS; `max(1e-7, 1.25*(1-cos_llama)+1e-7)` for cosine loss.
   Store old 1.05-headroom results as diagnostics. These numbers are declared
   before candidates. For zero vectors use abs/norm, not cosine. For staged
   accumulation add a rounding guard derived from FP32 operation count and
   sum(abs(products)); for integer dots count floating scale/group reductions,
   not integer multiplications. Document the conservative bound and int32
   overflow maximum. A bad total-error result cannot be waived by that bound.
7. Validate held-out inputs against frozen ceilings. If a finite llama stress
   case is pathological, use a strict fallback for that input/shape class; no
   budget from NaN/Inf. If a class lacks coverage, leave it unadmitted. No numeric
   pin may be changed automatically after candidate results are observed.
8. Replace the always-false global admission stub with a small explicit mapping
   from family, shape/staging and arithmetic variant to admitted evidence.
   Expose actual selections in diagnostic output. Do not label the whole engine
   strict when selected kernels use admitted approximations. An admission record
   allows testing a candidate; production selection still requires task acceptance.
   Tests of v1 history remain v1; current dispatch tests read current admission.
9. Retain PPL<=1.01 on both spans, recurrence<=0.02 and OPT-058 functional checks.
   For teacher-forced top-1 differences, calibrate full-vocabulary logit max/RMS
   error on reference-only captures, freeze a per-position margin bound equal
   to twice the admitted max logit error, and admit only top-1/runner-up swaps
   within that bound. Record all mismatch rates/KL; no arbitrary free-running
   token-identity requirement. Wider swaps fail screening even if NLL passes.
