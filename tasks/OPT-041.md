`warp_microtile` path (`WarpQK=true`):

- Eight 16×8 microtiles per KV tile: `m0 ∈ {0, 16}`, `n0 ∈ {0, 8, 16, 24}`.
- Frozen ownership: `tile_id = (m0 / 16) * 4 + (n0 / 8)` in `0..7`; owning warp is `tile_id % kNwarps`. Warp 0 owns tiles 0 and 4; warp 1 owns 1 and 5; warp 2 owns 2 and 6; warp 3 owns 3 and 7. Each physical warp therefore owns two microtiles.
- A warp that does not own a microtile skips it. No `__syncthreads` inside a microtile.
- The owning warp visits K in the **current virtual-warp partial order** and folds in the **current FP32 order**:

  ```text
  reduced[4] = {0,0,0,0}
  for vwarp in 0..3:
    cfrag[4] = {0,0,0,0}; cfrag_lo[4] = {0,0,0,0}
    for k0 = vwarp * 16; k0 < 256; k0 += 64:
      pack A from dual-F16 Q at (m0, k0) with tile16x8_half2_{i,j}
      pack B from BF16 K → F16 at (n0, k0) with tile8x8_{i,j}
      mma::mma_m16n8k16_f16_f32(cfrag, a, b)
      mma::mma_m16n8k16_f16_f32(cfrag_lo, a_lo, b)
    reduced[item] += cfrag[item] + cfrag_lo[item]
  scores[qcol * 32 + krow] = reduced[item] * attn_scale
    using tile16x8_i / tile16x8_j, same bounds as warp 0 today
  ```

- Extract the per-`k0` A/B pack + MMA into one `__device__` helper used by **both** `cparts` and `warp_microtile` so fragment association cannot drift.
- After the eight-microtile loop, **one** `__syncthreads__` so softmax can reuse `scores`. Do not add further QK barriers.
- Softmax, rescale, P×V MMA, register VKQ scatter, meta, and combine stay on the existing code paths.
- Pad dead K rows and dead query columns with zero A/B exactly as today. Do not write dead rows to global `vkq`.
