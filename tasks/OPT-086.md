because of OPT-074 coverage. Q8 and MMQ verdicts stay independent. Do not

`kernel_parity_pass`, `model_quality_pass`, `performance_pass`,

## Implementation

### Q8 decode

Compare control `r1_w4` vs installed `r2_w2`.

1. Structural correctness: legal alignment, staging reuse/invalidation,
   typed Q8_1 fields (production Q8 DP4A reads scale/values only; do not
   treat stored sums as a different type).
2. Q8 operation parity vs CPU/dequant reference (OPT-081 Q8_0 envelope) and
   same-math staging tests.
3. OPT-083/084 quality non-regression vs shipping baseline (shipping is
   currently `r2_w2`; if reverting, the quality/performance pair is vs
   `r1_w4` as the replacement control with the same freeze rules).
4. Component/E2E: repaired OPT-071 replay; all 48 GDN + 16 attention
   projection groups in true layer order including staging/norm; D2048
   3+10 pairs then five engine pairs; X-prefetch held fixed at the
   then-current MMQ decision or the shipping `fma_async_x` until the MMQ
   half of this task decides. Measure Q8 first if a four-configuration
   interaction screen is needed; that screen is at most one declared
   diagnostic, not an unbounded factorial.

OPT-070 D2048 rotating mixer n=10: `r1_w4` 7.455 ms vs `r2_w2` 7.506 ms
(paired CI favored control). Reuse for ranking only if identity remains
valid; keep/revert requires this sitting's confirmation.

### Prompt MMQ

Compare control `fma_async` vs installed `fma_async_x`, tile 128×128.

1. Q4_K MMQ parity vs CPU/dequant (`0.20*sqrt(K)` OR 5%).
2. Full-model quality under OPT-083/084.
3. Prompt performance: all 64 complete FFNs with staging, SwiGLU, down,
   residual; P4096 3+10 then five engine pairs; Q8 decision from the Q8
   half held fixed.

OPT-070 P4096 n=10: `fma_async` 887.292 ms vs `fma_async_x` 838.523 ms.
If kernel parity and model quality pass, formalize the keep when this
sitting still shows a positive complete-P interval and E2E non-regression.
