# OPT-093 — Factor paired-group Q4 integer dots
Status: pending. Dependencies: OPT-092. Coupled IDs: none.
Priority: P0. Target: remove repeated Q4 packed loads and scale/min work after the late_w4 decision.
Read [the post-088 protocol](PERFORMANCE-RECOVERY-POST-088.md).
Quality risk: factored FP32 association changes logits even with exact integer dots and sums.
Instrumentation: Q4 packed-load/DP4A/FP32 instruction counts, registers/spills, effective bandwidth, full FFN and D128/D2048+p95.

## Outcome

Factor paired-group Q4 integer scale/min work, with one strict-quality
production keep or a measured rejection. This is a new mechanism informed by
pinned llama `vec_dot_q4_K_q8_1_impl_vmmq`, not another OPT-076 warp sweep.

## Implementation

1. Create `pins/opt093_q4_factored_contract.json`, the iteration contract,
   `tools/opt093_q4_factored.py`, `tests/test_opt093_q4_factored.py`,
   `fixtures/opt093_q4_factored.json` and
   `evidence/optimization/opt093-q4-factored/REPORT.md`. Add
   `cuda/opt093_q4_factored_test.cu`, native
   `build/qw38-cuda-opt093-q4-factored-test`, Makefile
   `cuda-opt093-diagnostics` and existing replay/probe dependencies.
2. Exactly two timed configurations: `previous_selected` bound to OPT-092's
   production Q4/FFN identities, and `factored_pair_w4` = new Q4 selector
   `integer_q8_factored`, FFN `paired_integer`, four warps, FP32-scale Q8Block.
   Add selector/launch records in `cuda/q4k_decode_path.cuh`; implement single
   and paired bodies in `cuda/q4k_decode_dots.cuh`, launch wiring in
   `cuda/q4k_decode_dots.cu` and `cuda/full_scheduler.cu`. No prompt dispatch change.
3. Replace the per-group nibble/load pattern with one lane processing adjacent
   low/high-nibble groups from the same 32-byte Q4 payload. Use
   `pair=(lane%16)/4`, `pack=lane%4`, groups `(2*pair,2*pair+1)`;
   first K block `2*warp+lane/16`, stride 8 blocks for four warps. For each
   pair load the two packed words once and both corresponding Q8Block chunks.
   Compute exact int32 `dot0/dot1` and `sumq0/sumq1`, accumulate local
   `sum_d=d8_0*(dot0*scale0)+d8_1*(dot1*scale1)` and
   `sum_m=d8_0*(sumq0*min0)+d8_1*(sumq1*min1)`, then contribute
   `d*sum_d-dmin*sum_m` in FP32. Integer products stay int32 with proven bounds;
   d/min remain FP16 weight fields promoted to FP32. Preserve deterministic
   row-completion order and compute gate/up in separate accumulators sharing
   activation loads. No explicit FMA or approximate SiLU is added.
4. Keep the prior path as differential control. Same-math requires bit identity
   between the factored paired body and its own two independent factored
   projections plus the identical BF16 CUDA epilogue, and between graph/eager.
   Comparison with packed/late is quantized association, not bit identity.
   Use original independent CPU weight/staging references; do not share the
   new unpack helper with the host. Record file-level pinned MIT provenance.
5. Parity shapes M={1,3,17}, N=1, K={256,512,2048,5120,17408}; random seed89,
   with zero/cancellation/minmax/half-rounding at M3 K256. At K5120/17408 use
   16 sampled rows×4 vectors; include odd Q4 block count K256 and masked
   second block, aligned/2-byte-aligned weight pointers and output sentinels.
   Guard scalar-load fallback for unaligned packed words and prove it executes.
   Production screen covers all 64 FFNs: gate/up=(17408,1,5120),
   down=(5120,1,17408), prefix2048, control+candidate 1+3 AB/BA, one engine pair.
6. Entry trigger: OPT-090 evidence must show Q4 instruction/reduction cost
   remains material, or the packed control is still selected. If late's
   surviving profile is demonstrably bandwidth-limited without material dot
   instruction stalls, finish `no_go_bandwidth_bound` without a new kernel.
   Screening must save ≥0.10 ms/token. Full Q uses strict PPL ≤1.01 and
   recurrence ≤0.02 versus the current control and frozen anchors; the OPT-091
   candidate-specific 1.015 exception does not admit `factored_pair_w4`.
7. After Q, 3+10 full rotating FFN pairs and five uninstrumented pairs each at
   D128/D2048+32 with p95, plus one P4096 guard. Keep at most
   `integer_q8_factored`/`paired_integer`; otherwise restore previous pins.
   Report whether reduced instructions actually saved complete elapsed time.

## Acceptance

- Exact integers, typed staging, no overflows/nonfinites, all staged association
  and internal same-math cases pass. Kernel tolerances and flags are unchanged.
- Full Q and complete FFN saving/CI plus D128/D2048+p95 pass, or retain control.
- Independent verdicts: `kernel_parity_pass`, `model_quality_pass`,
  `performance_pass`, `production_kept`.
- `claims_throughput: true`; a no-go or instruction-count reduction alone is
  not a throughput improvement.
