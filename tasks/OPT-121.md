## Outcome and evidence

Investigate the largest compulsory traffic source: weights read during dense
single-token inference. The [inventory](../pins/tensor_inventory.json) contains
about 7.16 GB of Q8_0 and 1.46 GB of Q6_K in addition to Q4_K. Previous
OPT-100/102/104 repacks were lossless layout experiments; this task explicitly
tests smaller numerical representations with generated-text admission.
Read [OPT-115](OPT-115.md) and [OPT-116](OPT-116.md).

Use llama quantization and MMV/MMQ consumers and ds4's
`../ds4/cuda/mmq/mmq.cuh`/`ds4_repack.cu` as implementation references.
ds4's native MXFP4 routed-expert path in `ds4_cuda.cu` preserves an already
MXFP4 source model and uses FP4 MMA for batched work. Requantizing this Qwen
Q4_K_M artifact is a different approximation; FP4 tensor-core speed at prompt
matrix shapes does not promise a batch-one decode win.

## Implementation

1. Rank tensor roles by actual bytes read/token and sensitivity using a frozen
   calibration set distinct from OPT-116 admission inputs. Include GDN/mixer
   Q8 projections, attention Q6/Q8 projections and the Q6 output head; exclude
   whole embedding-table bytes from a one-row lookup traffic estimate.
   Report net candidate savings including scales/packing. Preserve norms and
   other small sensitive tensors unless evidence makes them material.
2. Freeze at most three complete model configurations: selective Q8→a supported
   4-bit format; an extension including justified Q6 roles; and one native
   block-scaled FP4 weight/activation configuration only if source/toolchain
   and quality feasibility support it. A format/role change counts as a new
   candidate. Keep sensitive roles at baseline precision based on calibration,
   not held-out answer tuning. Do not run a combinatorial per-layer search.
3. Derive disposable device/repack-cache representations from the authenticated
   pinned GGUF. Never overwrite/download a replacement model or describe the
   result as identical quantized arithmetic. Key cache identity by GGUF,
   conversion policy/calibration digest, role map, encoding and architecture.
   Document irreversible information loss and startup conversion time.
4. Implement real packed decode and prompt consumers for the chosen roles.
   Use a supported existing lower-bit encoding where possible. Do not relabel
   Q4_K bits as FP4, infer native instructions from a datatype name, or expand
   the entire model to a dense shadow. For FP4 record generated instructions,
   scaling/activation staging and actual supported SM120 shapes. Stop that
   candidate if the implementation capability is absent.
5. Account for temporary conversion buffers and replacement of raw resident
   weights; retaining both raw and compressed whole-model GPU copies is not a
   memory saving. Prompt fallback must fit the live 128K reserve and its data
   conversion/weight rereads must be timed. Keep canonical source on host as
   needed without changing artifact authentication.
6. Validate the new quantizer/packed operation independently, then full OPT-116
   NLL and free-running quality, especially reasoning/tool/code outputs and
   long GDN recurrence. Authenticate quality execution of every changed role.
   Run complete P4096/D128/D2048 screens and acceptance including output-head,
   staging, first-token and model preparation costs. Report actual bytes saved
   and time saved separately; do not infer throughput from bitcount alone.
