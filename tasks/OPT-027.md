### Persistent stream-K (required behavior)

Host launch (Ada+ always-on for this RTX 5090 production shape; do not re-introduce the pre-Ada 75% tile-efficiency skip):

1. `ncols1 = 16`, `ncols2 = 2`, `nbatch_fa = 32`.
2. `ntiles_x = ceil(token_count / ncols1)`; `gqa_ratio = query_heads / kv_heads` (6); `ntiles_z_gqa = ceil(gqa_ratio / ncols2)` (3); `ntiles_dst = ntiles_x * ntiles_z_gqa * kv_heads` (4096-row production: 256 × 3 × 4 = 3072); `ntiles_KV = ceil(kv_len / nbatch_fa)` with `kv_len = start_position + token_count`.
3. `occupancy = cudaOccupancyMaxActiveBlocksPerMultiprocessor` of the persistent kernel (≥ 1 required).
4. `nsm = multiProcessorCount` (RTX 5090 is 170; query live, do not hardcode as a correctness gate).
5. `max_blocks = occupancy * nsm`.
6. `nblocks_raw = min(max_blocks, ntiles_KV * ntiles_dst)`.
7. `nblocks_rounded = (nblocks_raw / ntiles_dst) * ntiles_dst`.
8. `efficiency_loss_percent = nblocks_rounded > 0 ? 100 * (raw - rounded) / raw : 100`.
9. `nblocks = efficiency_loss_percent <= 5 ? nblocks_rounded : nblocks_raw`.
10. Launch `grid.x = nblocks`, `grid.y = 1`, `grid.z = 1`, 128 threads, occupancy-2 `__launch_bounds__`.
11. Each block walks linearized `kbc = blockIdx.x * total_work / nblocks` … `kbc_stop` over `ntiles_KV * ntiles_dst` (same `iter_k * iter_j * iter_z_gqa * kv_heads` decomposition as llama.cpp). Whole tiles write unnormalized VKQ / max / den into `output` (and per-col stats). Fractional seams write packed fixup into aliased `meta`.
12. Combine: if `nblocks % ntiles_dst == 0 && nblocks > ntiles_dst`, uniform fixup; else if `ntiles_dst % nblocks != 0`, general fixup; else no extra combine (each block owned whole tiles). After combining VKQ/den, apply the existing output-gate sigmoid exactly as `fattn_stream_k_combine_kernel` does. Do not skip the gate.

Do not write `score_workspace`. Candidate K/V versus staging stays exact. Prepare does not mutate committed cache.
