# OPT-065 — Retune MMQ tiles with the active pipeline preserved

Status: pending. Dependencies: OPT-059, OPT-061. Coupled IDs: none.
Primary target: P4096 FFN. Read
[the batch protocol](PERFORMANCE-RECOVERY-2026-09-11.md).

## Concrete gap

OPT-053 kept FMA plus double-buffered Y at I128/J128 and reported occupancy1.
The old tile choice predates that resource change. Current
`launch_quant_mmq_mma_y_ij` enables the pipeline only for I128/J128; choosing
a different existing tile silently returns to the old non-pipelined dispatch.
An ordinary parameter sweep would therefore conflate tile and pipeline changes.

Read `cuda/quant_mmq_mma.cuh::quality_mma_process_tile`, `quality_shared_ints`,
`quality_rows_per_warp`, `launch_quality_mma`, pipeline dispatch/occupancy
helpers and `launch_quant_mmq_mma_y_ij`; `full_scheduler.cu::execute_prompt_ffn_projections` call
sites; and pinned llama `mmq.cuh`/`mmq-config-ampere.cuh` mappings.

## Implementation

1. Instantiate exactly four Q4 configurations: `(I,J)=(128,128)` control,
   `(64,128)`, `(128,64)`, `(64,64)`. All use the current accepted FMA/Y pipeline
   on full tiles. Extend the pipeline launcher and occupancy helper together;
   report the actual template variant, not only requested I/J.
2. Preserve `kNtx`, `kNi`, `kSum` formulas and static assertions. Verify all
   lane-to-output indices using small unique-pattern matrices before timing.
   Accumulation order within each output stays unchanged as far as the mapping
   permits. Use v2 numerics where output rounding changes, not exact equality
   between different reduction algorithms.
3. Compute dynamic shared allocation for the actual format and active buffers.
   The existing helper reserves `QualityI*kQualitySramMax` for all formats;
   investigate a format-specific allocation only if the required row stride and
   metadata extents are proven from the code. Treat allocation-only change as
   part of the variant identity. Query real occupancy after setting opt-in bytes,
   capture ptxas registers/local bytes, and refuse launches beyond device limits.
4. Keep synchronous tail/misalignment handling. Extend an aligned full-tile
   pipeline independently of fallback; tests must show the fallback is selected
   for output or prompt tails. Do not retune stream-K, physical microbatch or
   activation quantization. Keep FFN shared-Y and SwiGLU-Q8 staging.
5. Measure gate/up shape 17408× 5120 and down 5120× 17408 at 4096 prompt rows.
   Select one gate/up tile and one down tile if distinct winners are supported;
   avoid per-layer autotuning. Complete FFN replay includes staging and residual
   epilogues. Apply no new tile to Q6/Q8 by accident.
6. Once Q4 outcome is known, use one existing large Q8 and one skinny Q8 shape
   as cross-family regression checks of shared helpers, without a second tuning
   grid. Record effective dispatch and restore all unsupported paths unchanged.
