# OPT-077 — Parallelize the one-token GDN state reduction

Status: pending. Dependencies: OPT-070, OPT-071, OPT-073. Coupled IDs: none.
Priority: P1 after Q4 admission; target: 48 decode GDN cores/token.
Read [the post-069 protocol](PERFORMANCE-RECOVERY-POST-069.md).
Quality risk: high, recurrent arithmetic; state precision/layout stay FP32.
Instrumentation: captured committed state and complete GDN replay are added.

## Evidence and implementation

1. Confirm OPT-071 still observes `launch_gdn_prepare_tiled` selecting
   `kSequentialWindows` for one token. Current recurrence launches 48 CTAs and
   each output lane loops twice over 128 key elements, with serial lane-0 Q/K
   norms. OPT-052's prompt preprocessing does not replace this decode path.
   Entry requires >=0.10 ms/token plausible saving from corrected core time;
   record no-go if dispatch or attribution disproves the opportunity.
2. Add one-token optimized recurrence beside `prepare_recurrence_window`.
   Keep convolution separate, precompute Q/K norms once per key head, and
   distribute the key reduction among threads while loading contiguous value
   columns of the existing row-major FP32 state. Use a 2D key/value tile with
   register state shards and warp/shared reduction; write each candidate cell
   once. Bound to two layouts: value tiles 16 and 32 columns, four warps/CTA.
   Grid is value_heads x ceil(value_width/value_tile), not 48 single CTAs.
3. Retain FP32 recurrence, decay semantics, grouped/tiled value-head mapping,
   gated output norm and public state layout. Pinned llama's warp-sharded
   `gated_delta_net_cuda` motivates parallelism, but its transposed state is
   not a drop-in layout. No persistent transpose, lower-precision state, scan
   rewrite or prompt-path change in this task. If conversion proves necessary,
   reject this bounded design and document the separate storage problem.
4. Replay captured log_decay/beta/convolution input, gate/norm and committed
   states at D128/D2048. Reset each candidate state from the same snapshot
   outside timing. Complete cost includes convolution, normalization, recurrence,
   gated output and any required preparation. Core-only speed is diagnostic.
5. Calibrate changed recurrent reduction against independently evaluated FP64
   sampled state/output and actual pinned llama GPU recurrence on the same
   inputs, following OPT-059's predeclared policy. Full finite state checks,
   restored same-path graph/eager equality and atomic rollback are mandatory.
   Run both quality spans and short/long recurrence before any install.

`tests/test_opt077_gdn_decode.py`; extend repaired component replay with one
explicit `decode-gdn` family. No generic stateful benchmark framework.

reference: 16 selected state/output coordinates x 4 updates per held-out

rounds over 48 layer states. Quality and state tests are separate named phases.
