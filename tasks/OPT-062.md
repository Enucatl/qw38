# OPT-062 — Put admitted cooperative Q4 dots on every decode FFN leg

[the batch protocol](PERFORMANCE-RECOVERY-2026-09-11.md).

## Change

Revisit the existing OPT-046 implementation using real-input v2 quality and
streaming timing. Do not begin by writing another dot kernel. Current
`paired_staged` gate/up and `launch_quant_mmv_prequant` bypass the Q4 selector;
simply changing `kSelectedQ4DecodePath` is incomplete.

Read `cuda/q4k_decode_dots.{cu,cuh}`, `cuda/q4k_decode_path.cuh`,
`cuda/quant_mmv.cu::launch_quant_mmv_prequant`,
`cuda/full_scheduler.cu::execute_ffn`, `cuda/ffn_decode_path.cuh`, and the
OPT-046 rejection/OPT-049 keep. Preserve both historical controls.

1. Define only three complete-FFN configurations: current packed paired-staged
   control; cooperative integer Q8Block shared-stage gate/up plus integer down;
   and a half-scale staging candidate only if OPT-059 admits its exact semantics.
   Start at 4 warps/row, the measured OPT-046 winner. No warps×staging×fusion
   Cartesian sweep. If the half-scale layout is not admitted, skip it explicitly.
2. For the Q8Block candidate, quantize normalized BF16 once, call
   `launch_q4k_coop_mmv_prequant` for gate and up into existing FP32 buffers,
   run existing BF16 SwiGLU, then use cooperative down through `matrix_vector`.
   This intentionally uses separate gate/up calls for the first admission.
   Compare complete FFN against the current paired control, not OPT-045's
   obsolete separate baseline. OPT-063 owns integer paired fusion.
3. Make prequantized dispatch explicit about staging type. A `Q8Block*` function
   may dispatch only compatible Q8Block kernels; it must not reinterpret that
   pointer as Q8_1 because a global selector changed. If half-scale wins, stage
   its distinct layout and call its typed/internal launcher. Account for buffer
   alignment, bytes and invalidation when workspace storage is reused by Q8/Q6.
4. Add diagnostic dispatch records for actual gate, up and down launch variants
   and staging count. Record those during graph capture as well as eager work.
   Test that selecting integer reaches all three legs with one gate/up stage
   and a separate down stage. A constant saying integer is not sufficient proof.
5. Keep the Q4 scale/min layout exact. Independently test all eight group indices,
   high/low nibbles and negative activation sums. For half-scale candidates,
   use the OPT-059 format ID, not the existing misleading llama-style name.
   A failure against FP64 staged math is a kernel defect; the old CUD-001
   reduction-order miss alone is not the production gate.
6. Wire the accepted complete configuration into current selectors/admission,
   recapture FFN graphs, and confirm selected/effective settings agree. Keep
   strict reference tests selecting the strict launcher explicitly. Update
   historical pin assertions only when they erroneously inspect current source;
   leave old measured fixtures and rejection verdicts unchanged.
