# OPT-053 — Optimize MMQ scaling and tile staging

Status: pending. Dependencies: OPT-044, OPT-045. Primary target: P.
Read [the shared protocol](PERFORMANCE-RECOVERY-2026-09-10.md).

## Test execution contract (mandatory)

The test author must define `smoke`, `correctness`, and `acceptance` commands
in this dossier and make the new GPU test require `QW38_CUDA_TEST_TIER`, failing
closed when it is missing. Smoke is limited to compile/small probes, correctness
uses reduced samples without model-scale P/D oracles, and acceptance alone may
record performance evidence; each tier must list its phases, sample counts,
model loads, and skipped work. Reuse cached builds/binaries and emit phase
timestamps so implementation loops cannot launch the expensive default.

## Change

Work from `cuda/quant_mmq_mma.cuh::quality_mma_process_tile`, not the old scalar
MMQ or Rank-1 path. Current production already has integer MMA, ldmatrix A,
shared-Y gate/up, fused SwiGLU staging and selected I=128/J=128 FFN tiles.
Use OPT-043's **MMQ-only** gap after removing normalization cost to choose work.

1. Preserve integer fragment operations and quantization initially; introduce
   explicit FMA in dequant-scale accumulation where OPT-044 permits it. Compare
   scale loads and repeated address calculations to pinned llama
   `mmq-load-tiles.cuh`, `mmq-vec-dot.cuh` and its selected Ampere configuration.
   Hoist invariant pointer/stride/scale expressions; specialize admitted full
   tiles so tail branches are not selected unnecessarily.
2. Inspect compiler register/spill and profiler barrier/load data. Build one
   two-stage tile loader using asynchronous copies for the already packed Y
   buffer and/or prefetch packed weight words into registers. Keep Q4_K min
   corrections and Q6_K subscales identical. Packed GGUF weight bytes still need
   decoding: a cp.async of compressed bytes is not a decoded MMA tile. Do not
   blindly double the whole SRAM footprint; budget staging portions and overlap
   only safe lifetimes. Require SM120-compatible primitives and a synchronous
   fallback for tails/misalignment.
3. Compare component time for actual gate/up/down and wide/skinny Q8_0 roles,
   tokens 512/1024/2048/4096 and tails. Keep the existing 128×128 tile unless
   this changed register/staging premise justifies a small new sweep. A compact
   lossless repack is allowed only if counters show a load/unpack bottleneck,
   its layout round-trips exactly, and resident bytes plus 128K reserve fit.
   Do not re-run rejected OPT-024 D2R or OPT-028 stream-K unchanged.

Reference ds4's `cuda/mmq/ds4_mmq.cu` launcher boundary and `VENDOR.md`: it
retains much of llama's implementation. Use focused MIT techniques with file
provenance, not a wholesale ggml stub/backend import.
