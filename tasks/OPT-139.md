# OPT-139 — Normalize NCU evidence and authenticate production kernel identity

Status: done. Dependencies: OPT-138. Coupled IDs: none.
Priority: P0. Plan impact: none; existing release and quality gates retained.

## Outcome

Turn successful counter collection into trustworthy per-launch evidence. The supplied post-OPT-138 batch reports working counters, but typed fields remain null. The current reporter matches counters by family alone and can label any nonzero throughput as a supported mechanism; repairing parsing must not activate that shortcut.

## Scope

Extend the existing OPT-138 collector, reporter and focused tests. Preserve full raw NCU output or a report artifact, not only stdout_tail. Parse machine-readable output with the standard library; retain metric name, value, unit, launch identity, phase, workload, visible position, shapes, selectors and binary identity. Keep each launch separate, including units and normalization for stalls; never sum percentages or compare warp-sum totals from unlike replay workloads.

Authenticate D128 and D2048 separately against production traces. Trace decode_attention_vec128_path_for_position and replay overrides: the accepted hybrid dispatch can select vec128_online at D2048, so a warp_query replay is not automatically evidence for that gap. Select the largest-duration production kernel within each selected family and collect only its identified launch/range. Keep enclosing replay totals separate from target-kernel counters.

Populate supported typed slots, including DRAM/L2, SM/tensor activity, active warps, stalls, registers and spills where available. Unsupported or malformed values remain null with reasons; measured zero remains zero. Require phase, engine, workload, kernel and replay-boundary matches before report admission. A throughput value alone cannot establish a mechanism. Require named source/SASS observations and corroborating counters; retain candidate=null when those are absent. Prefill decode-attention counters remain explicitly ineligible until OPT-140.

## Verification and completion

Add focused parser/report cases for multiple launches, quoted CSV, units, missing metrics, real zeros, phase cross-contamination, selector mismatch and throughput-only false admission. Run the existing OPT-138 host tests and one bounded authenticated collection per selected decode shape; reuse valid full raw captures when possible. Retain 1200 s prompt-ffn timeout and declared aggregate budgets; no permissions changes or full metric sweep.

Deliver evidence/optimization/opt139-counter-identity/REPORT.md with raw-artifact links, typed counter records and valid or explicitly unknown mechanisms. Done requires working structured parsing and identity rejection, not merely another successful NCU exit. No production changes or throughput keep claim.
