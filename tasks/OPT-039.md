### Kernel behavior (frozen)

Candidate `warp_query`:

- Grid `(24, 16)` (`blockIdx.x = query_head`, `blockIdx.y = part`); block `(32)`. One warp owns one query-head/partition pair.
- Each lane owns eight consecutive dimensions: `dim = lane * 8 + {0..7}` covering `head_width == 256`.
- Shared Q scratch is 256 FP32 values (plus a scalar inverse). No CTA-wide KV tile. No `__syncthreads` in the KV-row loop. `__syncwarp` after Q setup is allowed; warp shuffles imply warp sync.
- Q RMS + partial RoPE runs **once per warp at kernel start**, not per KV row. Lane 0 performs the existing ordered FP32 sum-of-squares over all 256 query dimensions, then `inverse = 1 / sqrtf(sum / width + 1e-6)`. Broadcast inverse with `__shfl_sync`. Scale by `query_scale`, apply the existing pair RoPE formula over `pair = lane; pair < rotary_width/2; pair += 32`, then load eight Q values into registers. Part 0 writes `normalized_query`. Empty and non-empty parts each normalize independently so parallel partitions do not race on `normalized_query`.
- Contiguous partitions stay `part_begin = (part * L) / 16`, `part_end = ((part + 1) * L) / 16` with `L = position + 1`. Empty parts (`part_begin == part_end`) skip the KV loop and emit `max = -INFINITY`, `den = 0`, `numerator[:] = 0`.
- Each KV row: lane-local eight `q * bf16_to_fp32(K)` products with `__fmul_rn` / `__fadd_rn`, `__shfl_down_sync(0xffffffff, …)` reduction (offsets 16,8,4,2,1), lane 0 divides by `sqrtf(256)`, broadcast score with `__shfl_sync`, online FP32 max/denominator update, eight register VKQ accumulators. Physical committed addressing and candidate-versus-committed isolation match `load_kv_tile_rows` (`token < position` committed, `token == position` candidate).
- After the loop, write existing `partial_vkq` / `meta` layout (`query_head * n_parts * 256 + part * 256 + dim`, meta `{max, den}`). Invoke the unchanged merge.
- Gate sigmoid stays **once after merge**.
- Staging stays `stage_chunk_rows`. Score workspace is not written.

Retain as the A/B baseline and as production until a keep: `partitioned_grouped_decode_attention` + `merge_decode_kv_parts` at 16/16.
