## Implementation

1. Build current release and traced scheduler objects through OPT-057. Record
   all effective selectors, binary/flag identities and outputs for tokens
   `[42, 3649]`. In a focused baseline diagnostic, compare eager, FFN graph,
   and traced eager execution, resetting to identical state. Capture all needed
   residual taps during one token traversal, not one traversal per filter.
2. On the first nonfinite, narrow to the first failing layer and boundary:
   input norm, mixer projections, GDN/attention output, residual, FFN norm,
   gate/up, activated, down, final residual. Dump finite counts, first index
   and input hashes. Check activation staging cache invalidation, normalized
   buffer reuse, trace callback lifetimes and workspace initialization. Compare
   to a fresh untraced run. Use one affected layer with saved inputs for diagnosis;
   no repeated 64-layer scalar oracle. Fix the minimal reproduced cause; do not
   assume the old rejection still describes current production.
3. If all current modes are finite, retain that reproduction and classify the
   old failure as historical or unreproduced. Do not invent a fix. Preserve the
   old fixture. Make current nonfinite failures hard errors in the new probe,
   with a behavioral regression for any diagnosed code defect.
4. Run the exact eight original functional token sequences on pinned llama
   and Quartz. Decode token 271 with the pinned tokenizer; record the next
   token, top-two logits and up to 16 free-running tokens per case. This is
   diagnosis, not a new expected answer. If llama also emits formatting text,
   establish the prompt/scorer defect rather than attributing it to CUDA dots.
5. Freeze `pins/production_quality_v2_inputs.json` using the actual supported
   no-thinking chat template (`src/template.cpp` and its fixtures), with an
   explicit assistant answer boundary and the same eight questions/answers.
   Generate at most 16 tokens, strip only leading/trailing whitespace, and
   accept exactly one of A/B/C/D matching the fixed answer. Reject extra words,
   empty output, a second answer or answer-changing parser shortcuts. Do not
   mask logits to the four choices. Run pinned llama first; if it cannot pass
   a case, report invalid baseline and investigate rendering before tuning.
6. Keep teacher-forced NLL and free-running functional evaluation as different
   operations. Generalize the existing llama bundle writer to an explicit case
   list so it can score the eight original probes and both 1024-target spans.
   Do not alter the old seven-case reference in place. Freeze missing held-out
   llama scores on the OPT-044 offsets and hashes. Reuse the model across cases;
   prefill long contexts in chunks and score the exact target positions.
7. Add a v2 verdict that requires every named case and its reference. Missing
   held-out authority is `incomplete`, never passed by omission or finite-only
   checks. Keep PPL <=1.01 and recurrence incremental NLL <=0.02. Preserve old
   QLT-001 and OPT-056 verdicts alongside v2. Register this baseline in OPT-057
   so later candidates can reuse immutable reference outputs.

## Fast tests and bounded execution

tap, missing authority/case, empty/extra-text answer, valid whitespace, and

logit arrays for parser/verdict tests. Run existing template tests only if its
implementation changes; normally this task uses its current behavior.

× 3 execution modes, one model load, full finite checks and five saved taps.

tokens maximum). Phase `quality-baseline` is explicit one-time acceptance:
2 spans × 1024 scored targets plus the existing short/long recurrence pair,
one reference result per engine. No repetitions or throughput claims.

```sh
uv run pytest -q tests/test_opt058_quality_baseline.py tests/test_quality.py
uv run python tools/run_optimization_task.py --task OPT-058 --mode feedback --phase scheduler
uv run python tools/run_optimization_task.py --task OPT-058 --mode feedback --phase functional

```

Each feedback phase has the shared 300-second deadline. Stop at the first
nonfinite and use the saved layer capture. The one-time complete quality freeze
is separately timed; do not run it on every edit. If baseline is invalid, retain
failure evidence and continue independent instrumentation, not arithmetic promotion.
