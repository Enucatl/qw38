# OPT-094 — Conditional GDN timing replication
Status: pending. Dependencies: OPT-093. Coupled IDs: none.
Priority: P1. Target: resolve tile32 only if OPT-090 demonstrated a repairable measurement defect.
Read [the post-088 protocol](PERFORMANCE-RECOVERY-POST-088.md).
Quality risk: reordered recurrent reductions can accumulate drift or mutate committed state.
Instrumentation: per-round recurrence/conv/gate/copy counts, complete 48-layer GDN time, independent restored rounds, D128/D2048+p95 and recurrent state.

## Outcome

Conditionally replicate OPT-077 tile32 on demonstrably repaired timing, or
record `no_reopen`. Prior control 12.51649 vs tile32 11.89390 ms had CI
−0.1643 to 1.4094 ms; D2048+32 was 878.416 vs 866.012 ms. This was an
inconclusive performance result, not numerical-policy rejection. Neither
OPT-082 nor model-quality relaxation alone authorizes a repeat.

## Implementation

1. Create `pins/opt094_gdn_replication_contract.json`, the iteration contract,
   `tools/opt094_gdn_replication.py`, `tests/test_opt094_gdn_replication.py`,
   `fixtures/opt094_gdn_replication.json` and
   `evidence/optimization/opt094-gdn-replication/REPORT.md`. Reuse
   `build/qw38-cuda-opt077-gdn-decode-test`, component replay and engine probe
   through `cuda-opt094-diagnostics`. No new recurrence kernel is requested.
2. Eligibility is deterministic: require OPT-090
   `gdn_reopen_eligible=true` with an actual before/after defect record in
   timing boundaries, repetition units, capture identity or restoration. If
   absent, report no-reopen and stop without GPU work or source changes.
   Repair only the demonstrated defect in the replay/diagnostic owner before
   measuring; preserve the original OPT-077 evidence.
3. Exactly two configurations in `cuda/gdn_decode_path.cuh`: `sequential`
   versus existing `tile32`. `cuda/gdn_decode_recurrence.cuh` and
   `cuda/gdn_step.cu` arithmetic/layout are unchanged. Four warps/CTA,
   grid=(48,4) for 48 heads ×128 key ×128 value; state remains FP32 row-major;
   convolution stays separate. No tile16 screen. All preceding kept selectors
   are fixed and both configurations recapture graphs independently.
4. Correctness reuses OPT-077 widths 8/32 and updates 1/4, plus production
   width128, key_heads16/value_heads48, four updates, held-out GDN slots46/47.
   Full tiny references; production 16 sampled state and output coordinates
   per update. Preserve its actual candidate-vs-sequential bounds max_abs
   ≤5e-5, RMS≤5e-6 and one-update sampled FP64 max_abs≤5e-4; zero nonfinites.
   Historical sequential GDN-002 5e-8/5e-9 is unchanged. These are existing
   distinct contracts, not a new kernel tolerance. Require bitwise graph/eager
   and reset/replay equality for the same candidate, and committed-state isolation.
5. Feedback screen at prefix2048: complete conv+recurrence+gate+required copies
   over 48 actual captured layers, 1+3 AB/BA, one D2048+32 pair. Stop on
   negative mean saving. Surviving candidate runs full Q at unchanged 1.01/0.02,
   including recurrence-long and checkpoint/save/restore plus cancellation before
   publication. Include output-projection cost only if both sides' declared
   complete boundary includes it; identify it separately to prevent double counting.
6. This single replication predeclares 3 warmups +30 independently restored
   AB/BA **pairs per prefix** at 128 and 2048, separate acceptance phases.
   Require two-sided 95% Student-t lower bound >0 (df29=2.04523) and mean
   saving ≥0.10 ms/token at each. Do not pool with OPT-077 samples, add rounds
   or rerun an inconclusive outcome. Then five engine pairs at each
   D128/D2048+32 with p95 and one P4096 guard. Promote only `tile32` if all
   gates pass; otherwise `sequential` remains selected.

## Acceptance

- No GPU replication without a specific repaired defect; an old wide CI is
  insufficient. The new unit of observation is auditable.
- Existing numeric/state gates, full Q, fixed 30-pair component intervals and
  D128/D2048+p95 guards pass or produce a terminal measured rejection.
- Independent verdicts: `kernel_parity_pass`, `model_quality_pass`,
  `performance_pass`, `production_kept`; no-go uses false plus not-applicable reason.
- `claims_throughput: true` only for the intended conditional timed path;
  no-reopen evidence emits false.
