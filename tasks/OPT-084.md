# OPT-084 — Resolve installed Q8/MMQ paths under v3

Status: pending. Dependencies: OPT-081, OPT-082, OPT-070, OPT-073.
Coupled IDs: none.
Priority: P1. Target: formal keep/revert for OPT-064 and OPT-066.
Read [the post-080 protocol](PERFORMANCE-RECOVERY-POST-080.md).
Quality risk: Q8 row grouping can change FP32 association; MMQ X-prefetch
must preserve stage lifetimes. OPT-070 inconclusive retain remains
historically correct; this task is the successor.

## Outcome

Convert OPT-070's unresolved installed selectors into independent
keep/revert decisions under v3. Q8 and prompt MMQ are **separate
subdecisions**. One family unresolved must not contaminate the other.
Do not assume installed `r2_w2` or `fma_async_x` should be kept.

### Q8

Compare control `r1_w4` versus installed `r2_w2` on mixer K5120/K6144 with
direct Quartz-vs-llama v3 admission. OPT-070 complete rotating mixer
slightly favored `r1_w4` (7.455 vs 7.506 ms) with E2E non-regression;
issue a real keep/revert once numerical admission exists. Measure Q8 at
D2048 with X-prefetch held at the then-current MMQ pin.

### Prompt MMQ

Compare `fma_async` versus installed `fma_async_x` on applicable Q4 prompt
families (tile 128×128, all 64 complete FFNs). OPT-070 measured a large
P4096 complete-FFN saving for `fma_async_x`; if v3 numerics and quality
pass, convert that unresolved installed state into a formal keep. Measure
MMQ at P4096 with the Q8 decision from this task held fixed, or with the
shipping Q8 pin if the Q8 verdict is still pending in a split phase.

## Implementation

1. Require OPT-082 `candidate_testable=true` for the families each
   subdecision needs. Missing coverage blocks **that** subdecision only.
2. Prove actual production launches after separate graph capture. Do not
   toggle only a test TU selector. Keep OPT-058 staging invalidation.
3. Apply frozen OPT-081 Quartz-vs-llama limits on calibration and held-out
   cases. Held-out cannot enlarge limits. llama-vs-FP64 drift is diagnostic.
4. Each subdecision reports independent
   `candidate_v3_admitted` / quality / performance / `production_kept`.
   Revert only when the replacement/control also passes admission; do not
   undo unrelated scheduler fixes. Inconclusive still means leave shipping
   unchanged and label admission unresolved.
5. OPT-073 engine non-regression plus PPL/recurrence as applicable.
   Absolute quality remains visible and may `release_blocked` without
   forcing a kernel revert by itself.
6. Reuse OPT-070 replay shapes: Q8 all 48 GDN + 16 attention projection
   groups in layer order including staging/norm; MMQ all 64 complete FFNs.
   Acceptance is 3+10 component pairs then five target engine pairs per
   family, split by phase.
