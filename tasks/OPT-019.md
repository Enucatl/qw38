### GDN quality kernel (do not vendor `gated_delta_net.cu`)

Replace production fused recurrence only. Convolution stays `prepare_convolution_chunk_parallel`. Implement the quality recurrence in a new `cuda/gdn_fused_quality.cuh` included from `cuda/gdn_step.cu` (**do not add a Makefile object**, **do not edit `NVCCFLAGS`**).

Production shape `GdnConfig{16, 48, 128, 128, 4}` (`S_v = 128`, `H = 48`):

- Grid: `dim3(value_heads, 1, value_width / 4)` = `(48, 1, 32)`.
- Block: `dim3(32, 4)` (128 threads, `num_warps = 4`). Column `col = blockIdx.z * 4 + threadIdx.y`. Lane `threadIdx.x`.
- Register state: `float s_shard[4]` with `s_shard[r] = S[r*32 + lane][col]` (llama.cpp `gated_delta_net_cuda<128>`).
- Per token: cache `k_reg[4]` / `q_reg[4]`; warp-reduce L2 for Quartz `query_inverse` / `key_inverse` (keep the existing formulas, including `query_inverse` extra `/sqrt(key_width)`); `decay = expf(log_decay)`; `kv_col` via warp-reduce of `s_shard * k_scale`; `delta = (value[col] - prediction) * beta`; fused `s_shard = decay * s_shard + k_scale * delta`; `attn` via warp-reduce of `q_scale * s_shard`.
- `__launch_bounds__(128, 2)` (llama.cpp occupancy 2). Occupancy via `cudaOccupancyMaxActiveBlocksPerMultiprocessor` must be ≥ 1; target 2 is allowed and expected, not a pin-loosen if only 1 is achieved.
- No `__syncthreads()` in the token loop (warp-level only).
- Write token-major FP32 recurrent output and final candidate recurrent state. Do not mutate committed convolution/recurrent buffers.
- Partial configs other than 128-wide stay on Rank-2 fused (production is 128-wide). Reject unknown `GdnScanPath` with `cudaErrorInvalidValue`.

Provenance in the quality kernel header (and `docs/sources.md`): llama.cpp `gated_delta_net.cu` / `gated_delta_net.cuh` at `cc83d7b4824f73cfdda4dfbb47ee39804f71b328` (MIT, The ggml authors). ds4 has no GDN analog.

Algebra remains FP32 GDN-002: same convolution warm-up (existing kernel), decay, beta, grouped/tiled value-head mapping (`value_is_tiled`), and candidate/commit isolation. Decode one-token GDN is unchanged.
