## Evidence and implementation boundaries

1. In the private llama authority adapter, disable recording during model/context
   setup, warmup and decode prefix. Synchronize, clear records and start a fresh
   epoch immediately before the measured window. `begin_run()` currently
   precedes warmup; changing only epoch does not remove those records. Size the
   pool from bounded expected operation counts or drain per token; any dropped
   record fails acceptance. Do not just enlarge 8192 and retain contamination.
2. Give Quartz one epoch per measured sequence or explicit absolute token
   offsets. Add stable parent/scope IDs and map both engines to the same complete
   family boundaries. Count 64 gate/up pairs, 64 downs, 48 GDN cores, 16 attention
   cores and one logits projection per decode token, expanding fused membership
   only for counts. Each interval contributes once. Do not add enclosing FFN
   to its leaves or label all ggml MUL_MAT as mixer.
3. Separate shipping graph wall, eager diagnostic work, instrumentation
   overhead and uncovered wall/CPU/copy time. Exclude prefix/graph creation
   from decode latency. Attribute D2H and commit consistently. Obtain one
   short graph-aware timeline if tools permit; otherwise retain explicit
   graph proof limits and uninstrumented family ablations. Sum concurrent
   intervals only as work; compute union on a common epoch.
4. Repair OPT-061 replay: consume the corresponding captured activation at
   each replayed layer/role, including attention output, rather than reusing
   layer-0 residuals. Persist full required vectors, not only prefixes or
   hashes. Capture once in production arithmetic/graph-compatible execution.
   Cache identity covers model, full token/input hashes, source/build, flags,
   selectors, layer/role, staging and state. Validate --capture-key and actually
   load its bundle. No recapture on an identity-matched invocation.
5. Rotate all 64 actual weights in order, or explicitly declare a bounded
   representative set >2x L2. Use pooled events and resolve after the complete
   round: `event_ms` inside the layer loop currently synchronizes each layer.
   Correctness restores each captured role; timings exclude capture and reset
   copies. Persist distinct host samples and layer inputs for numerical use.
6. Rank remaining family time, matched llama excess where covered, and maximum
   removable time. Include actual Q4/Q8/GDN/attention launches and hardware
   readback. Do not force totals to reconcile by inventing an overlap. Report
   all unknown time; >5% unexplained measured-window time or invalid call counts
   makes gap attribution incomplete. Repair causes before downstream ranking.
