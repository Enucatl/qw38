Args> cudaError_t quartz_launch_kernel(Kernel kernel, dim3 grid, dim3 block, std::size_t shared, cudaStream_t stream, Args&&... args)` — if `pdl_uses_launch_ex()` and a `PdlScope` is active and the stream is not capturing and `pdl_kernel_can_use(kernel)`, build `cudaLaunchConfig_t` with one `cudaLaunchAttributeProgrammaticStreamSerialization` (`programmaticStreamSerializationAllowed = 1`) and `cudaLaunchKernelEx`; else `kernel<<<grid, block, shared, stream>>>(args...)`. ### Scope (required)

PDL applies only to **live successive kernels on `prompt_compute_stream_` during fused `execute_prompt_chunk`**, covering the ungraphed mixer / GDN / attention chains (plus embedding, mixer residual writes, and logits that sit on the same stream). Explicit exclusions:

| Launch | PDL |
|---|---|
| Mixer Q8 quantize + quality MMA (in/out projections) | yes, inside `PdlScope` |
| `prepare_gdn_gate_rows`, parallel conv, warp-column quality, `gdn_gated_output_rows` | yes |
| `split_attention_rows`, staging, OPT-026 fattn `stream_k` (`grid.z=2`), combine, `launch_fp32_to_bf16`, attention-output Q6_K MMA | yes |
| Embedding / scatter / logits rms on `prompt_compute_stream_` | yes (same stream; cheap) |
| `execute_prompt_ffn` / `execute_prompt_ffn_projections` live or captured | **no** |
| `cudaGraphLaunch` of prompt FFN graphs | **no** (not a kernel Ex launch) |
| `SchedulerGraphs::create` capture of `execute_prompt_ffn` | **no** (capturing) |
| Decode `execute_ffn` / `launch_attention_prepare` / `launch_gdn_prepare_tiled` | **no** |
| `prompt_copy_stream_` copies | **no** |

Wrap `execute_prompt_chunk`'s mixer+core+output-mixer (and embedding/logits) in `PdlScope`. Do **not** enter `PdlScope` around `execute_prompt_ffn`, `execute_prompt_ffn_projections`, or graph create/replay. Direct `<<<>>>` in that scoped region go through `quartz_launch_kernel`. Helper launchers used from both FFN and mixer (`launch_quantize_mmq_q8_1`, residual/norm row kernels) must honor `PdlScope` + capturing, so FFN capture and live FFN stay `<<<>>>`.
