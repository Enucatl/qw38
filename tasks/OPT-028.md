### Stream-K (required behavior)

Quartz has no MoE `ids_dst`, no channel/sample batching. `I = 128`, `J = selected_mma_mmq_prompt_tile()` (128), `qk = 256`, `ITER_K = 256`, `blocks_per_ne00 = columns / 256` (already required `columns % 256 == 0`).

Host launch for one Q4_K/Q6_K quality MMA:

1. `nty = ceil(output_rows / I)`; `ntx = ceil(prompt_rows / J)`; `ntiles_dst = ntx * nty`.
2. `nsm = multiProcessorCount`.
3. `tiles_nwaves = ceil(ntiles_dst / nsm)`; `tiles_efficiency_percent = ntiles_dst == 0 ? 100 : 100 * ntiles_dst / (nsm * tiles_nwaves)`.
4. If path is `stream_k`: `nblocks = (tiles_efficiency_percent >= 90) ? ntiles_dst : nsm` (llama.cpp NVIDIA rule; sm_120 is NVIDIA). If path is `stream_k_nsm`: `nblocks = nsm`. If path is `off`: existing 2D `grid(nty, ntx)`.
5. `fixup_needed = ntiles_dst % nblocks != 0`.
6. Launch stream-K kernel `grid.x = nblocks`, `grid.y = 1`, `block dim3(32, 8)`, same dynamic shared as tiling.
7. Each block walks linearized `kbc = blockIdx.x * (ntiles_dst * blocks_per_ne00) / nblocks` … `kbc_stop` aligned to `ITER_K/qk` (1). Decode `(it, jt)` from `kbc / blocks_per_ne00`. Whole K-ranges (`kb0_start == 0` through full K) write dst. The last fractional K-range writes `tmp_fixup[blockIdx.x * (J * I)]` in I-major tile layout matching llama.cpp (`j * I + i`).
8. If `fixup_needed`, launch `mul_mat_q_stream_k_fixup` analog: `grid(nblocks, I/32)`, `block(32, 4)` (llama.cpp uses `nthreads/2` warps). Sum prior partials into dst. Skip blocks that wrote a complete tile start or wrote no data.

Do not change load-tiles or vec_dot math. Reuse the existing quality `process_tile` loop with `[kb0_start, kb0_stop)`. Do not vendor ggml fastdiv; for Quartz `ntzw = 1` integer `/` and `%` on `int64_t` kbc are enough (`ntiles_dst * blocks_per_ne00` fits in 30 bits on production 4096 FFN: gate `4352 * 20 = 87040`).

At production 4096 FFN with J=128, llama.cpp `stream_k` efficiency is ~98% (gate `4352` tiles) and ~94% (down `1280` tiles), so `nblocks = ntiles_dst` and **fixup is skipped**. That path is linearized 1D tiling versus current 2D tiling. `stream_k_nsm` forces `nblocks = nsm` and **does** split K plus fixup; include it so the A/B can still win a true stream-K occupancy mapping at oracle length.
