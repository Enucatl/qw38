Follow the OPT-015 ranked recovery sequence in order, stopping early if the 2K gate already passes. Keep every frozen numeric and exact-state envelope. Do not treat 8K, 32K, 128K, or QLT-001 as speed gates.

- Constraints: keep C++17, CUDA 13.0.2, `sm_120`, Makefile `NVCCFLAGS --fmad=false` and host `-ffp-contract=off` unchanged, BF16 activation/KV storage, FP32 residual and GDN recurrence, production `GdnConfig{16, 48, 128, 128, 4}`, GDN-002 `kScanWindow = 64`, OPT-008 `kPromptChunkRows = 4096` and `prompt_chunk_rows_ = min(4096, capacity)`, workspace byte formula `160,380,416 + 96*C + 404,992*R`, OPT-011 fused overlapped production plus retained unfused serial path, OPT-012 prompt FFN graphs (replay only when `token_count == 4096` unless Rank 4 is admitted below), OPT-013 parallel associative GDN scan retained as an alternate, SES-002 candidate-versus-committed isolation, Engine session capacity `131072`, and all frozen SCH-002/OPT-008/OPT-009/OPT-011/OPT-012/OPT-013/OPT-014/CUD-002/GDN-002/ATN-002/OPT-005 numeric and exact-state gates. Adapt focused MIT-licensed llama.cpp techniques with file-level provenance (`plan.md:66-68`); use `../ds4` only as already-qualified MIT adapter-without-ggml inspiration, not as vendored code and not as a same-GGUF baseline. - Non-goals: 8K/32K/128K throughput claims; QLT-001 128K quality; CMP-002/CMP-003 30-sample comparative gates; swapping production Q8_0 off the byte-exact OPT-009 tiled kernel; sparse, windowed, or compressed attention; MoE expert streaming; mHC; DSpark; forking DwarfStar; production cuBLAS/cuDNN; changing decode MMV; changing `kPromptChunkRows`; loosening CUD-002 (`5e-4` / `2.5e-4`, exact Q8 staging on the scalar reference, zero non-finites), OPT-013 (`5e-8` / `5e-9`), OPT-005 tiled-attention envelopes, or Q8_0 byte equality; editing `plan.md`; treating ds4 tok/s as a denominator.
