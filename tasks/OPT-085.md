# OPT-085 — Re-evaluate Q4 decode candidates

Status: pending. Dependencies: OPT-075, OPT-076, OPT-082, OPT-084. Coupled IDs: none.
Priority: P0. Target: at most one Q4 production path under the new ladder.
Read [the post-080 protocol](PERFORMANCE-RECOVERY-POST-080.md).
Quality risk: changed Q4 association/reduction; staging typedness stays fixed.
Instrumentation: actual eager/graph dispatch; repaired OPT-071 replay.

## Outcome

Reopen OPT-075 cooperative integer Q4, OPT-076 late-reduction Q4, and current
packed control. First gate is OPT-082 kernel parity. Do **not** require
OPT-074 production-family admission or Quartz-vs-llama production projections.
`opt074_coverage_unadmitted` is not a blocker. Issue independent kernel-parity,
quality, performance, and keep/revert verdicts. Select at most one Q4
production path.

Historical complete-FFN signals (identity must be reconfirmed if used for
ranking): packed ~16.43 ms vs `integer_q8_paired` ~11.77 ms; packed ~16.42 ms
vs `late_w4` ~9.82 ms.

## Implementation

1. Configurations, no new fusion/tile/compiler/half-scale grid:
   - control: shipping `packed` / `paired_staged`;
   - OPT-075 survivor: `integer_q8` / `paired_integer`;
   - OPT-076 survivor: `integer_q8_late` / `paired_integer` `late_w4`.
   Four warps/row and FP32-scale Q8Block stay fixed. Half-scale Q8_1 remains
   forbidden.
2. Ladder A/B: structural correctness (hard invariants, typed staging,
   `sum_q` vs `sum_x` pairing). Then OPT-082 Q4_K CPU-dequant association plus
   same-math checks (paired vs separate, fused vs unfused, eager vs graph).
   Candidates that fail kernel parity are rejected before quality.
3. Survivors run the OPT-083/084 quality suite with `--quality`. Compare
   against the OPT-084 shipping Quartz baseline (primary) and pinned llama
   (inspectable). A known baseline defect does not reject a candidate that
   does not worsen it. A meaningful NLL/PPL/recurrence/continuation
   regression rejects even if parity passed.
4. Then existing component/E2E methodology: complete 64-layer rotating FFN
   on repaired OPT-071 captures; 3+10 AB/BA; five D2048+32 pairs; separate
   graph capture per configuration; prove actual launches. Existing OPT-075/076
   timings may rank only if source/selector/capture identity remains valid;
   a keep requires this task's specified fresh confirmation.
5. Select at most one Q4 path. If no candidate beats packed on performance
   after passing A–C, retain packed. Reports must include:
   `kernel_parity_pass`, `model_quality_pass`, `performance_pass`,
   `production_kept` as independent booleans. Do not use OPT-074 unadmitted
   as a reason.

## Acceptance

- Each configuration has the four independent verdicts.
- Packed remains the control; a keep requires parity + quality + measured
  complete-FFN saving with a positive paired CI and E2E non-regression.
- Historical OPT-075/076 reports are unmodified.
- `claims_throughput` is true only if `production_kept` and the measured
  tok/s/component evidence is this sitting's.
