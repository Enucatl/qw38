# OPT-147 — Screen a prefill 8x8 flash-attention tile

Status: pending. Dependencies: OPT-135, OPT-140, OPT-144. Coupled IDs: none.
Priority: P1. Plan impact: none.

## Outcome

Test one concrete production-boundary P4096 candidate that changes Quartz's
current 16x2 prompt-attention tile organization to a llama-shaped 8x8 tile.
This is a hypothesis screen, not a claim that llama's tile can be copied
unchanged. Unknown source/SASS mechanism is allowed at screen admission; it
must remain an explicit unknown in the report. A candidate can ship only after
correctness, quality, state/memory and whole-engine target/guard evidence.

## Candidate and boundaries

Candidate ID: prefill_attention_8x8_v1. Keep BF16 authoritative state,
OPT-111 arithmetic semantics, causal masks, chunking and final-token output
policy. Change only the prompt-attention tile shape, indexing, head masks,
shared-memory/register layout and required launch/workspace integration. Count
conversion, staging, softmax, merge and output consumers in the complete family.
Do not re-port OPT-111 wholesale, add a tile sweep, alter GGUF/checkpoints,
or use decode attention as evidence.

Screen exactly P4096, one warmup plus three alternating complete-family pairs,
rotating the applicable layers and real inputs. Correctness covers 8x8 versus
control at prompt lengths 1, 32, 128, 2048 and 4096, causal tails, GQA head
masks, finite outputs and prompt-to-decode handoff. The disconfirming result is
screened_out when complete-family time does not improve or any numerical,
launch, chunk or output invariant fails. The screen is allowed with a concrete
candidate even when counters or SASS cannot name the mechanism.

## Acceptance

A screened-in survivor runs OPT-058 candidate quality, graph/eager equality,
checkpoint/cancellation, populated 131072-capacity memory/reserve checks, then
OPT-135 target_guard_v2 acceptance with P4096 prefill target and D128/D2048/
D8192/D32768 decode-only and complete-request guards. Keep only with all required
quality/state/memory/whole-engine gates. Mechanism remains unknown unless
separately evidenced; it is not a substitute for those gates.

Deliver the existing task artifacts under evidence/optimization/opt147-prefill-8x8/,
with frozen contract, raw screen/acceptance samples, launch identity and an
independent reconstruction of one P4096 pair. Missing required work is
incomplete/blocked, never no_opportunity.

## Execution requirements

Read TASK-TESTING-STRATEGY.md and the performance checklist. Use
QW38_CUDA_TEST_TIER=correctness|screen|acceptance, the shared GPU lock, one build,
fixed inputs and declared 300/1200/7200-second ceilings. No broad profiling batch
or automatic tile sweep.
