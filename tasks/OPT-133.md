# OPT-133 — Capture Nsight Systems decode activity on the admitted stack

Status: done. Dependencies: OPT-125, OPT-132. Coupled IDs: none.
Priority: P1.

## Outcome

Run bounded Nsight Systems captures on the **shipping** decode path
(`decode_segments8`, post-OPT-132 stack) and publish hardware-level answers to
OPT-125's open attribution question: are the ~10.5 ms/token **unobserved**
intervals real removable GPU idle, missing graph/API work invisible to CUDA
event leaves, or host-side launch/submission delay?

Deliver parsed summaries, raw `.nsys-rep` traces, profiler overhead versus an
uninstrumented twin run, and a reconciliation table against OPT-125 CUDA-event
intervals for the same prefixes and early/middle/late windows. Diagnostics and
evidence only — **no production selector, kernel, or dispatch change**.
`claims_throughput=false`, `claims_performance_improvement=false`.

## Implementation

1. **Native diagnostic binary** — add
   [`cuda/opt133_decode_nsys_trace_test.cu`](../cuda/opt133_decode_nsys_trace_test.cu)
   and Makefile target `build/qw38-cuda-opt133-decode-nsys-trace-test` under
   `cuda-opt133-diagnostics`. Reuse OPT-132 session setup on
   `decode_segments8` / combined OPT-118+119 stack. Workloads:
   - `identity` — assert shipping stack, lazy 4-byte D2H, hooks ready.
   - `nsys-window` — greedy sample/eval loop for one **12-token** window
     (early / middle / late) on a **256-output** trajectory; bracket capture
     with `cudaProfilerStart()` / `cudaProfilerStop()` around the measured
     window only (warm prefix tokens outside the range). Emit the same
     `QW38_OPT060`-style attribution records as OPT-132 activity windows plus
     `instrumented_decode_only_wall_ms`, `window_label`, `prefix`, and
     `nsys_capture=true`.
   - `nsys-baseline` — identical window **without** profiler API markers for
     overhead pairing (native run only, no `nsys profile` wrapper).
   Prefixes: **128** and **2048**. Model:
   `models/Qwen3.8-27B-Q4_K_M.gguf`. Exclusive GPU sitting required; record
   unrelated GPU residents in sidecar metadata.

2. **Python runner** — add
   [`tools/opt133_decode_nsys_trace.py`](../tools/opt133_decode_nsys_trace.py)
   with phases:
   - `preflight` — image, nsys/ncu presence, stack identity, OPT-125 fixture
     load for reconciliation targets.
   - `capture` — for each `(prefix, window)` run paired:
     - **Baseline:** `./build/qw38-cuda-opt133-decode-nsys-trace-test
       --workload nsys-baseline ...`
     - **Nsight:** `nsys profile -o <run_dir>/trace-<prefix>-<window>.nsys-rep
       --force-overwrite true --trace=cuda,nvtx,cudart,osrt
       --capture-range=cudaProfilerApi --capture-range-end=repeat
       ./build/qw38-cuda-opt133-decode-nsys-trace-test --workload nsys-window
       ...`
     Retain stdout/stderr sidecars and `.nsys-rep` files under
     `build/optimization-runs/opt133/` and copy canonical traces to
     `evidence/optimization/opt133-decode-nsys-trace/traces/`.
   - `parse` — for each trace run `nsys stats --report gputrace --format json`
     (and `cuda_api_sum` when available) into structured JSON sidecars. Derive at
     minimum:
     - `gpu_busy_ms` — union of device-active intervals from the GPU trace
     - `gpu_idle_ms` — hardware idle within the capture window
     - `cuda_api_ms` — host CUDA API time overlapping the window
     - `graph_launch_count`, `graph_launch_ms`, `memcpy_ms`, `sync_ms`
     - breakdown by NVTX range name where present (mixer/gdn/attention/ffn/graph)
   - `reconcile` — load OPT-125 activity intervals for D128/D2048 and compute:
     - delta(`nsys gpu_idle_ms`, OPT-125 `unobserved_ms`) per window
     - fraction of unobserved explained by nsys idle vs API vs still-unresolved
     - call `classify_disjoint_intervals(..., profiler="nsight_systems")` only
       when `gpu_idle_ms` comes from parsed trace, not the current stub relabel
   - `overhead` — compare baseline vs nsys-wrapped `instrumented_decode_only_wall_ms`
     and report `nsys_overhead_ms` and `nsys_overhead_ratio`
   - `report` — write fixture + `evidence/optimization/opt133-decode-nsys-trace/REPORT.md`
     with findings, raw trace paths, overhead, reconciliation, and explicit
     answers to:
     1. How much of OPT-125 unobserved time is **proven GPU idle**?
     2. How much is **host/API submission** visible to Nsight but not event leaves?
     3. How much remains **unresolved** after both instruments?
     4. What is the **nsys wrapper overhead** on the bounded window?

3. **Contracts and wiring**

     [`tools/run_optimization_task.py`](../tools/run_optimization_task.py)
     (`QW38_OPT133_DECODE_NSYS_TRACE_RESULT=`).
   - [`fixtures/opt133_decode_nsys_trace.json`](../fixtures/opt133_decode_nsys_trace.json)
     — host-validated structure; GPU fields populated after capture phase.

4. **Host tests** — [`tests/test_opt133_decode_nsys_trace.py`](../tests/test_opt133_decode_nsys_trace.py):
