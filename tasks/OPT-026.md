### Production dispatch after A/B

- If winner is `occ2`: `launch_attention_prepare_chunk` for `token_count >= 16` launches the occupancy-2 whole-tile kernel. Scheduler unchanged aside from the enumerator.
- If winner is `stream_k`: scheduler `execute_prompt_chunk` attention branch calls `launch_attention_prepare_chunk_stream_k` with `partial_vkq = reinterpret_cast<float*>(prompt_projected_bf16_)` and `meta = reinterpret_cast<float*>(prompt_q8_)`. Those buffers are overwritten by the subsequent BF16 store and attention-output / FFN quantize. Component tests that call `launch_attention_prepare_chunk` without aliases keep the occupancy-2 whole-tile kernel so OPT-005 signatures and `scratch_unchanged` stay. A/B proves the stream-K envelope with explicit buffers.
- If A/B loses: `kSelectedFattnPath = "baseline"`; production stays occupancy-1 whole-tile. Optimized kernels may remain as non-production symbols so the A/B diagnostic still compiles.

`token_count < 16` stays tiled. Decode stays tiled/one-row.
