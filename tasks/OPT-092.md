# OPT-092 — Group same-input Q8 projections
Status: pending. Dependencies: OPT-091. Coupled IDs: none.
Priority: P0. Target: reduce decode mixer launch granularity with unchanged r1_w4 arithmetic.
Read [the post-088 protocol](PERFORMANCE-RECOVERY-POST-088.md).
Quality risk: wrong tensor/output mapping or stale shared activation staging could corrupt every layer.
Instrumentation: Q8 launch count, staging generations, exact output comparison, complete rotating mixer and two-prefix ITL/p95.

## Outcome

Group same-input Q8 decode projections into one launch per layer group, with
an admitted keep or measured retention of separate r1_w4 launches. Staging
reuse already exists in `matrix_vector`; the new mechanism is grouping launches.
OPT-086's r2_w2 lost: 7.504 vs 7.453 ms, CI −0.0824 to −0.0203 ms for
r1−r2. This task does not reopen that unchanged layout.

## Implementation

1. Create `pins/opt092_q8_grouped_contract.json`, the iteration contract,
   `tools/opt092_q8_grouped.py`, `tests/test_opt092_q8_grouped.py`,
   `fixtures/opt092_q8_grouped.json` and
   `evidence/optimization/opt092-q8-grouped/REPORT.md`. Add
   `cuda/opt092_q8_grouped_test.cu`, native
   `build/qw38-cuda-opt092-q8-grouped-test` and Makefile
   `cuda-opt092-diagnostics`, also building existing replay/probe targets.
2. Add a separate grouping selector in `cuda/q8_decode_path.cuh` with exactly
   `separate` (control) and `grouped_r1_w4` (candidate). Retain
   `dp4a_q8_1`/`r1_w4`, one row/CTA, four warps/row for all row buckets.
   Implement `q8_coop_mmv_grouped_r1_w4` in `cuda/q8_decode_dots.cuh`, with
   launcher declarations in `cuda/q8_decode_dots.cuh` and definitions in
   `cuda/q8_decode_dots.cu`.
   A fixed four-entry descriptor contains tensor pointer, row count and output
   pointer; grid-x ranges map CTAs to the original row and tensor. Three-entry
   attention groups use a zero-length fourth entry. No model weight repack.
3. In `cuda/full_scheduler.cu`, group only projections of the same freshly
   normalized residual: 48 GDN groups with (M,N,K)=(10240,1,5120),
   (6144,1,5120), (48,1,5120), (48,1,5120); 16 attention groups with
   (12288,1,5120), (1024,1,5120), (1024,1,5120). Consume the existing single
   Q8_1 staging per group; keep invalidation on every new activation write,
   despite pointer reuse. GDN output (5120,1,6144) remains separate. Attention
   output is Q6_K, not Q8, and stays separate. Preserve all output pointers and
   ordering at the existing consumer boundary.
4. Preserve each row's K iteration, DP4A, FP32 accumulation and reduction
   order verbatim from the r1_w4 body; only CTA-to-tensor mapping changes.
   Grouping should reduce input-projection launches from 240 to 64, a reduction
   of 176 per token; verify actual counts. No extra staging or descriptor upload
   per projection. Bind immutable descriptors to model/workspace identity and
   graph lifetime, and include any required per-token work in timing.
5. Correctness shapes: grouped M={1,3,17,0}, K={256,5120}, N=1, then the two
   production input groups plus separate output group. Test first/last/empty
   descriptor, sentinel boundaries, two different inputs at identical addresses,
   changed model/workspace identity and graph/eager dispatch. Small cases full;
   production each tensor 16 rows×4 inputs. Require exact staged bytes and
   bitwise FP32 outputs versus separate r1; use corrected OPT-082 staged parity
   and typed-sum checks without tolerance changes.
6. Screen control+candidate across all 48 GDN and 16 attention mixer groups,
   including unchanged output projections, at prefix2048 with 1+3 AB/BA and
   one D2048+32 engine pair. Proceed only if OPT-090 attributes measurable
   input-projection launch cost and screening shows ≥0.10 ms/token complete
   mixer saving. Run/reuse Q under default 1.01/0.02; if current control uses
   the OPT-091 concession, require exact same-math quality outputs and preserve
   the total frozen-anchor ceiling. Then 3+10 complete-mixer pairs, five pairs
   each at D128/D2048+32 and one P4096 guard. Keep one grouping selector only.

## Acceptance

- No newly quantized activation representation; staging generation and tensor
  mapping are exact, including graph reuse. Actual projection count falls by 176.
- Positive complete-mixer CI and ≥0.10 ms/token saving, full Q evidence and
  D128/D2048+p95 guards pass, or `production_kept=false` retains `separate`.
- Independent verdicts: `kernel_parity_pass`, `model_quality_pass`,
  `performance_pass`, `production_kept`.
- `claims_throughput: true`; screens and rejected/no-go outcomes claim no gain.
