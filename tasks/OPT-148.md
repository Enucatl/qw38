## Outcome

Test one source-faithful flash-style/vector attention candidate against Quartz's
D2048 vec128_online_decode_attention, using llama's flash_attn_ext_vec only as
an implementation reference and matched boundary. The candidate may be screened
from a precise hypothesis without a proven mechanism. Do not label counter
differences as a causal explanation until source/SASS evidence exists.

## Candidate and boundaries

Candidate ID: decode_attention_flash_vec_v1. Preserve BF16 KV, partial RoPE,
GQA ratio, online-softmax outputs and OPT-137 dispatch at positions >=8192.
Change one D2048 short-decode path: tiled K/V traversal and online reduction,
with all query preparation, conversion, masking, merge and output-gate costs
charged. Keep D128 warp_query and long-context MMA as guards. No n_parts sweep,
threshold change, OPT-130 revival, persistent cache or new tolerance.

Correctness covers positions 0, 1023, 1024, 2047, 2048, 4096 and 8192 with
rotating real layers and sampled FP64 references. Screen complete attention with
one warmup and three paired rounds at D2048 and one short engine pair. Screened
out means no complete-family gain or any invariant failure. Candidate NLL is
required for an arithmetic change, but mechanism proof is not a screen gate.

## Acceptance

A screened-in survivor runs OPT-058 long/held-out quality, state and graph
boundary checks, checkpoint/cancellation, populated 131072-capacity fit, then
OPT-135 acceptance with D2048 decode-only target and complete-request, D128,
D8192, D32768 and P4096 guards. Ship only if every required gate passes; causal
mechanism stays unknown when unsupported.

Deliver evidence/optimization/opt148-short-decode-flash/ and independently
recompute one D2048 component result. Missing candidate work is blocked, not
no-opportunity. No broad NCU sweep.

## Execution requirements

Use the shared testing strategy, explicit CUDA tiers, fixed identity/input matrix,
GPU lock and existing deadlines. Reuse the current attention harness and add
only candidate-specific correctness/screen wiring.
