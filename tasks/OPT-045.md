# OPT-045 — Parallelize normalization and use admitted FMA

Status: done. Dependencies: OPT-044. Coupled IDs: none. Primary target: P and D2048.
Read [the shared protocol](PERFORMANCE-RECOVERY-2026-09-10.md).

## Change

In `cuda/full_scheduler.cu`, retain the current serial implementations of
`rms_norm_fp32_to_bf16`, `rms_norm_rows_fp32_to_bf16`,
`residual_add_norm_fp32_to_bf16`, and its row variant as strict references.
Add optimized siblings: one CTA per residual row; each thread accumulates
strided squares using `fmaf`; warp shuffle sum followed by a shared warp-sum
reduction; one inverse scale broadcast; coalesced multiply/store with a single
BF16 rounding. Test 128 and 256 threads for width 5120. Preserve epsilon and
the order of norm-scale multiplication until independently validated.

Apply the same measured design to `scheduler_primitives.cu::rms_norm` and
128-wide GDN gated output normalization, using one warp per head or a small
CTA. Do not bundle MMV, attention QK, or recurrence rewrites. The fused residual
sum is written once in FP32 and normalized cooperatively. Keep the actual
residual value separate from its normalized BF16 result.

Compare sqrt/divide to admitted rsqrt as a second A/B, not an unexplained
compiler change. Graph/eager comparisons select identical optimized kernels.
Do not require new reductions to reproduce the serial reference's exact bits;
OPT-044 governs cross-path comparisons.

## Acceptance

the small kernel. Require new production-numerics gates and full P/D guards.

dependency evidence in `evidence/optimization/opt045-parallel-norm/`.
Add task contract/fixture and `tests/test_opt045_parallel_norm.py`.
Run that test, `tests/test_cuda_scheduler_primitives.py`,
