## Implementation decisions

Keep skinny α/β on OPT-023 `mma_i32_j128`. Keep decode `q8_mmv_bf16` on GGUF 34-byte layout **unless** a keep installs in-place SoA, in which case only large-mixer tensors are rewritten and decode of those tensors uses a SoA addressing variant of the same MMV math (CUD-001 envelopes unloosened). Keep `launch_q8_mmq_bf16_reference` and `launch_q8_mmq_bf16_variant` as the OPT-009 byte-exact pair. Do not route production Q8_0 through `launch_quant_mmq` or `launch_quant_mmq_mma`. ### Technique (inspiration, not a copy)

Rewrite a Quartz-native path. Do not copy `ds4_mmq_d2r.cu`, `proto_gemm_dense_q8_d2r.cu`, or `ds4_repack.cu`.

**SoA layout** (byte-neutral payload plus 64B pad after the scale plane, matching ds4 kind-5):

```
dq_bytes = output_rows * (columns/32) * sizeof(half)
pad      = (64 - dq_bytes % 64) % 64
qs       at dq_bytes + pad, int8 [output_rows][columns] row-major
total    = q8_aligned_soa_bytes(output_rows, columns)
```

GGUF 34-byte blocks unpack to that layout with a small `launch_repack_q8_0_aligned` kernel written here.

**D2R GEMM:** CTA `dim3(32, 8)` (256 threads), I=128, J=128, `__launch_bounds__(256, 1)`, occupancy ≥ 1. Load aligned SoA qs with 16-byte vector loads (not `get_int_b2` on 34-byte blocks), load half scales, load existing D4 Y the same way quality MMA does, `ldmatrix` + `mma.m16n8k32.s8`, `acc += float(C) * d_w * d_y`. Output remains token-major FP32 `[prompt_rows, output_rows]`. Set `cudaFuncAttributeMaxDynamicSharedMemorySize` when shared exceeds 48 KiB. Do not add a Makefile object; keep the kernel in `quant_mmq_mma.cuh` included by `quant_mmv.cu`. Do not edit `NVCCFLAGS`.

Export from `cuda/quant_mmv.h`:

- `bool large_mixer_q8_output_rows(std::size_t output_rows) noexcept` — `output_rows >= 128`
- `std::size_t q8_aligned_soa_bytes(std::size_t output_rows, std::size_t columns) noexcept`
- `const char* selected_large_mixer_q8_path() noexcept` — `"quality_mma"` or `"d2r_soa"`
- `launch_repack_q8_0_aligned`, `launch_q8_mmq_d2r`, `q8_d2r_occupancy`

Pin the A/B winner string in `pins/opt024_mixer_q8_d2r_contract.json` as `selected_large_mixer_q8_path` and hard-code the same enumerator in the dispatcher.
