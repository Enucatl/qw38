# OPT-046 — Implement cooperative packed Q4_K decode dots

Status: pending. Dependencies: OPT-044, OPT-045. Primary target: D2048.
Read [the shared protocol](PERFORMANCE-RECOVERY-2026-09-10.md).

## Change

Retain `cuda/quant_mmv.cu::quant_mmv` packed FP32 path. Add a focused Q4_K
integer-dot implementation based on pinned llama `mmvq.cu::mul_mat_vec_q` and
`vecdotq.cuh::vec_dot_q4_K_q8_1`. Do not simply promote OPT-042's diagnostic:
its one-warp row, per-block shuffles and lane-0 fold leave much of the execution
design unchanged.

1. Add optimized Q8_1 staging in a distinct type/buffer contract. Use pinned
   llama's round/scale/sum semantics exactly for that staging variant; retain
   original FP32-scale Q8Block unchanged for strict calls. Start with unchanged
   Q8Block staging as a control so staging vs reduction effects are separable.
2. Map packed loads to four int8 products per instruction. Respect Q4_K's
   256-value, 144-byte blocks, 6-bit scales/minima and eight 32-value groups.
   For group g compute `dy * (d * scale[g] * dot(q4,q8)
   - dmin * min[g] * sum(q8))`; use integer intermediates with overflow bounds
   and FP32 scale/accumulation. Precompute activation sums once per group,
   not once per output weight row. Match any Q8_1 half-scale rounding to its
   own reference rather than assuming this formula is bit-equal to FP32 Q8.
3. Distribute K blocks across 4 warps per row (llama-style starting point).
   Each lane owns packed dot chunks and keeps independent accumulators through
   the K loop; reduce at row completion, not via eight lane broadcasts every
   block. Compare 1/2/4/8 warps per row, bounded to production gate/up
   17408×5120 and down 5120×17408. Clearly distinguish warps per **row** from
   the current selector's warps per CTA/rows per CTA.
4. Use aligned 32-bit loads where legal; Q4_K block size is a multiple of 16.
   Avoid byte arrays assembled back into words. Confirm DP4A and no spill
   regression in compiler/disassembly evidence. No tensor-core GEMM padded
   to batch 16 unless it wins a separately measured complete control.
5. Wire accepted output into `matrix_vector`/`execute_ffn`, with strict
   diagnostic selection. Recapture decode FFN graphs. This task does not fuse
   gate/up and does not change Q6_K or Q8_0 production dispatch.
