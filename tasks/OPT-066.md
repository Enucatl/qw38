## Rationale and limits

`quality_mma_process_tile` pipelines packed Y but synchronously loads and unpacks
Q4 weights at the top of each `kb0` iteration. OPT-061 must confirm this family
still has meaningful time to recover. This task tests raw packed-X prefetch;
it does not rerun OPT-053's Y-only experiment or introduce persistent weight
repacking. Use the accepted OPT-065 tile, even if that outcome was128× 128.

## Implementation recipe

1. Add one optional template parameter/path for a two-stage raw Q4 weight ring
   in shared memory. Keep the existing decoded X tile, accumulators, metadata
   math, Y pipeline and MMA instructions. Control is the current winning tile
   with no raw-X ring; candidate is the same tile with raw-X ring. No wider sweep.
2. For each output tile row and K256 block, copy the full144-byte Q4 block
   (9 aligned 16-byte chunks) to a 16-byte-aligned shared slot. Global row/block
   strides are multiples of16 for admitted Q4 shapes. Partition chunk copies
   across CTA threads; zero-fill invalid output rows in a guarded fallback or
   use the existing synchronous fallback. Do not issue out-of-range async loads.
3. Warm the first raw stage, wait for it, then unpack it into the existing
   decoded X tile. While MMA consumes that decoded tile and active Y, prefetch
   the next raw K block into the alternate raw slot. The next iteration waits
   before unpacking. Shared-slot reuse needs a CTA barrier after every consumer
   of the old slot finishes. Use explicit commit/wait group accounting that
   includes both the existing Y copies and new X copies; their groups cannot
   be reasoned about independently on the same per-thread async queue.
4. Write a short stage-lifetime table in the implementation report: warmup,
   iteration k load/unpack/compute, next-stage readiness, final drain. Test
   K256/512/768 to exercise warmup, alternating slot reuse and drain. Do not
   add a generic pipeline abstraction; this kernel has a fixed two-stage schedule.
5. Calculate extra shared bytes `2*I*144` plus alignment padding and existing
   `quality_shared_ints`. If that exceeds actual device opt-in limits, use a
   single prefetched raw slot whose lifetime is proven safe, or close as no-go
   with the resource calculation. Do not silently shrink the tile and combine
   two experiments. Query occupancy/registers/local memory for the exact kernel.
6. Keep all arithmetic byte-identical to the control when order is unchanged.
   Source-level async assembly is insufficient evidence: inspect SASS for
   load-to-shared instructions, spill traffic and actual launch attributes.
   Optional targeted counter evidence can explain a loss but is not required
   to reject a slower complete path. Wire dispatch only after acceptance.
